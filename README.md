# JavaScript Object & Constructor Function Exercises
This project contains three small exercises to practice working with objects and constructor functions in JavaScript. Each example can be run in the browser console or in a JavaScript file.

## Objects Created
1. Book Object - Created a book object that stores details about a book.
2. Animal Constructor - Built a constructor function called Animal to represent animals.
3. Student Constructor - Created a constructor function called Student to represent students.

## How To Run
1.	Copy the code for each exercise into a .js file or browser console.
2.	Open your browser’s Developer Tools → Console.
3.	Paste the code and run it to see the output.
